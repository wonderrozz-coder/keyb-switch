# История изменений

## 0.9.0 — 2026-11-06

Первая версия, которую не стыдно показать.

**Работает**

- Автопереключение раскладки после слова (`ghbdtn␣` → `привет␣`).
- Переключение на лету, до пробела.
- Двойной Shift: выделение → набираемое слово → последнее слово.
- Пунктуация внутри слова (`nt,z` = `тебя`) и после него.
- Защита от опечаток по частотности (`учше` не станет `exit`).
- Работа в терминалах (Punto-подобные аналоги обычно их исключают).
- Точность: 96% RU→EN, 99% EN→RU, ложных 0.21–0.29%.

**Технические решения**

- libhunspell через ctypes вместо `hunspell -a`: 0.003 мс против 40 мс на промахе.
- Вставка через `wtype`: не зависит от активной группы, не зацикливается.
- Решение по весам частотности, а не «словарь сказал да/нет».
- Статистика трёхбуквенных префиксов как тайбрейкер для коротких слов.

**Исправлено по ходу**

- Запятая ломала слово и превращала `ghbdtn,` в `приветб`.
- `min_word_length = 4` не давал работать `пщ`/`ещ`.
- Двойной Shift вставлял слово из старого буфера.
- `Watcher` не обновлял раскладку без событийного сокета.
- Ctrl+V ломал буфер слова.
- Уведомления по умолчанию выключены.
