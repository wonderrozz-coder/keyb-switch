## 2. «На английский переключает хуже: пщ ещ еру farm»

Воспроизвёл все ваши примеры — вы правы, и причины было две, обе неочевидные.

### 2.1. Слова короче 4 букв не проверялись вообще

`min_word_length = 4` отбрасывал `пщ` (2 буквы) и `ещ` (2 буквы) ещё
до всякой проверки. Отсюда ощущение «короткие слова не работают».

**Исправлено:** `min_word_length = 2`. Мусор теперь отсекается не длиной,
а сравнением доказательств (см. ниже).

### 2.2. Проверка орфографии слишком снисходительна

`еру` — это легальная (но крайне редкая) форма родительного падежа от
«ерунда». Словарь отвечает «слово существует», мы решали «значит, русское»
и отказывались превращать `еру` в `the`.

Проблема в самом вопросе: hunspell отвечает «это допустимая форма?»,
а нам нужно «это правдоподобное слово?».

**Исправлено: вместо «да/нет» теперь сравниваются веса доказательств**
(`kbswitch/frequency.py`), с использованием частотных словарей на 50 000 слов:

| доказательство | вес |
| --- | --- |
| слово в топ-4000 частотного списка | 3 |
| слово в топ-20000 | 2 |
| легальная форма по словарю, но не в списке | 1 |
| неизвестно | 0 |

Побеждает раскладка с бо́льшим весом; при равенстве — не трогаем:

```
пщ   / go       0 vs 3  ->  go           (было: не трогал)
ещ   / to       0 vs 3  ->  to           (было: не трогал)
еру  / the      1 vs 3  ->  the          (было: не трогал)
афкь / farm     0 vs 3  ->  farm         (было: не трогал)
here / руку     3 vs 3  ->  не трогаем   (оба настоящие слова)
ghbdtn/привет   0 vs 3  ->  привет
```

### Про «может, сравнивать по двум буквам сначала»

Проверил замером, и ваша идея работает — но как **вспомогательное**
средство, а не основное:

| префикс | русских опознано | английских ложно |
| --- | --- | --- |
| 2 буквы | 92.8% | 1.1% |
| 3 буквы | 98.7% | 0.4% |
| полное слово | 98.2% | 0.1% |

Двух букв достаточно в 93% случаев ценой 1.1% ложных — это заметно хуже
полного слова. Поэтому префиксы используются только тогда, когда у обоих
кандидатов **слабые** доказательства (вес ≤ 1) и нужно решить, кто
правдоподобнее. Итоговый порядок:

1. вес по частотности — основной сигнал;
2. префиксная статистика — тайбрейкер для слабых случаев;
3. при равенстве — не трогаем.

### Результат по обоим направлениям (3000 слов реального текста)

| --- | --- | --- |
| исправлено | **99.8%** | **99.8%** |

Осталось 7 промахов из 3000: `here`/`руку`, `her`/`рук`, `hi`/`рш`,

Их трогать нельзя, это неотличимо.

## 3. «При использовании Shift вставляется другое слово, видимо из буфера»

**Настоящий баг, воспроизвёл.** Причина: при двойном Shift с пустым буфером
код брал `last_correction` — слово, исправленное **давным-давно** — и вставлял
его. Плюс срабатывание было слишком легко случайно вызвать.

**Исправлено четырьмя способами:**

1. **Вставляется только набираемое слово.** Если буфер пуст — последнее
   слово, но не старше `force_window_s = 6` секунд (`last_correction` больше
   не используется).
2. **«Чистое» двойное нажатие.** Между двумя нажатиями Shift не должно быть
   введено ни одного символа, иначе это обычный набор заглавной буквы.
3. **Ничего не зажато** (кроме самого Shift).
4. Не срабатывает при зажатом Ctrl (это ваш `Ctrl+Shift` для раскладки).

Проверено: набор `Shift+G` затем `hbdtn` больше не вызывает вставку.

## 4. «Раз так хорошо определяем язык — может, переключать на лету?»

**Сделано.** Слово исправляется **не дожидаясь пробела**: как только набрано
достаточно букв и доказательства уверенные.

```
набрано:  g h b d t      -> при "n" слово стало настоящим: переключились
стало:    п р и в е т
```

Настройки:

```toml
live = true              # переключать на ходу
live_min_length = 4      # сколько букв нужно для надёжного решения
live_interval_ms = 120   # не чаще, чем раз в 120 мс
```

Что делает это безопасным:

- исправление делается **только при весе доказательств 3** (частотное слово) —
  вслепую на лету не гадаем; при равенстве или слабых данных слово
  спокойно дописывается, и решает уже обычная проверка на пробеле;
- если переключение оказалось ошибочным, достаточно продолжать печатать:
  буфер хранит исправленный текст, и всё сходится само;
- регистр сохраняется (`Ghbdtn` → `Привет`);
- ограничение частоты (120 мс) не даёт устроить шторм вставок.

Проверено вживую: `ghbdtn` без пробела → `привет` с переключённой раскладкой.

Отключить, если мешает: `live = false`.
