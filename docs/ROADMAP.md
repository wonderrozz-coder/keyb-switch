# Roadmap и известные ограничения

Честный список: что работает, что нет, и что делать дальше.

---

## Известные ограничения (не баги, а природа вещей)

| Ограничение | Причина | Обход |
| --- | --- | --- |
| Поля паролей неотличимы | приложение не сообщает, что поле защищённое | внести менеджер в `autocorrect_blacklist` |
| `here`/`руку` не исправляется | слово настоящее в **обеих** раскладках | двойной Shift |
| Wayland-инъекция только через virtual-keyboard | другого легального способа нет | — |
| Выделение нужно сначала выделить мышью | primary selection появляется только после выделения | — |
| Часть Electron/Qt не принимает замену выделения | приложение не читает primary selection | срабатывает обычный путь (последнее слово) |
| Двухбуквенные слова решаются осторожно | слишком много ложных (`gj`, `vc`, `фр`) | двойной Shift |

## Что можно добавить

### Ближайшее

- [ ] **Меню в Omarchy** (`omarchy-menu`) вместо только CLI.
- [ ] **Свой чёрный список по приложениям** прямо из CLI:
      `keyb-switch ignore com.mitchellh.ghostty`.
- [ ] **Пресеты**: `keyb-switch preset strict|balanced|aggressive`
      (порог маржи, live, длина слова одним ключом).
- [ ] **Экспорт словаря исключений**: слова, которые никогда не переключать
      (`keyb-switch keep here руку`).
- [ ] **Индикатор** в баре: показать, что демон жив.

### Среднее

- [ ] **Обучение на пользователе**: запоминать отмены (двойной Shift после
      автопереключения = «зря переключил») и понижать вес таких слов.
- [ ] **Учитывать выделение при автопереключении** (сейчас — только двойной Shift).
- [ ] **Контекст слова**: если предыдущее слово английское, следующее чаще тоже.
- [ ] **Поддержка более двух раскладок** в автокоррекции (движок уже умеет N).
- [ ] **Своя статистика префиксов** из текстов пользователя (приватно, локально).

### Дальше

- [ ] **Другие композиторы**: Sway/niri/GNOME через абстракцию в `hypr.py`.
- [ ] **X11-ветка** через `xdotool` (сейчас только Wayland).
- [ ] **Пакеты**: AUR `keyb-switch-git`, `PKGBUILD` в репозитории.
- [ ] **Перевод интерфейса** на английский (сейчас CLI на русском).

## Как отлаживать «не сработало»

1. `keyb-switch log` — было ли исправление вообще.
2. `keyb-switch doctor` — живы ли права, словари, демон.
3. `tail -30 ~/.local/state/keyb-switch/daemon.log` — ошибки.
4. `keyb-switch typo <слово>` — что движок думает о перекладывании.
5. Класс окна: `hyprctl -j activewindow | jq -r .class` — не в чёрном ли списке.

Прислать в issue: что набрали, что получили, вывод `keyb-switch log`,
класс окна и `keyb-switch doctor`.
