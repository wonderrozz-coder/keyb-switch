# keyb-switch

Автоматическое исправление раскладки для Hyprland / Wayland — замена
Punto Switcher для Linux.

```
набрано:   ghbdtn␣        (хотели «привет», забыли переключить)
получено:  привет␣        (раскладка переключилась сама)
```

Работает во всех приложениях сразу: браузер, мессенджеры, редакторы,
**терминалы**, игры.

## Возможности

- **Автопереключение после слова** — `ghbdtn␣` → `привет␣`.
- **Переключение на лету** — слово исправляется, не дожидаясь пробела.
- **Двойной Shift** — принудительно переложить набираемое слово,
  последнее слово или **выделенный текст** (включая фразы).
- **Защита от опечаток** — `учше` не превращается в `exit`: программа
  отличает опечатку от ошибки раскладки по частотности слов.
- **Понимает словоформы** — `приветик`, `приветствую`, `Российской`.
- **Работает в терминале** — в отличие от многих аналогов.
- **Никаких всплывающих окон** и вмешательства в набор.

Точность на реальном тексте (Википедия, 2500–3000 слов):

| направление | исправлено | ложных срабатываний |
| --- | --- | --- |
| русское, набранное в EN | 96% | 0.21% |
| английское, набранное в RU | 99% | 0.29% |

Замер на случайных статьях Википедии (`scripts/benchmark.py`, 1500 слов).
Считаются только слова, где ошибка раскладки однозначна; неоднозначные
(настоящие слова в обоих языках) пропускаются и не портятся.
Решение принимается за 0.06–0.3 мс.

## Установка

```bash
git clone https://github.com/<логин>/keyb-switch.git
cd keyb-switch
./scripts/install.sh
```

Скрипт поставит зависимости, создаст virtualenv, установит udev-правило
(спросит пароль sudo), подготовит словари и запустит демон.

Подробно, по шагам, и для других дистрибутивов: [docs/INSTALL.md](docs/INSTALL.md).

**Требования:** Hyprland (или wlroots-композит с протоколом virtual-keyboard),
`wtype`, `hunspell`, `wl-clipboard`, Python 3.11+.

## Как это работает

```
физические клавиатуры (/dev/input/event*)
        │  только чтение, без перехвата (grab)
        ▼
   буфер текущего слова ─ буквы, пунктуация внутри слова ("nt,z" = "тебя")
        │                  Ctrl/Super сбрасывают буфер (это шорткаты)
        ▼
   решение: в какой раскладке это осмысленный текст
        ├─ частотность слова   (топ-4000 = 3, топ-20000 = 2, форма по словарю = 1)
        ├─ проверка опечаток   (слово на одну клавишу от частого слова?)
        └─ статистика префиксов (тайбрейкер для коротких слов)
        ▼
   исправление: switchxkblayout + вставка через wtype
```

Ключевые решения и почему они такие — [docs/DESIGN.md](docs/DESIGN.md).

## Использование

```bash
keyb-switch status         # состояние, раскладки, словари
keyb-switch log            # журнал исправлений (что во что)
keyb-switch force          # принудительно переложить (как двойной Shift)
keyb-switch typo ghbdtn    # показать, как перекладывается текст
keyb-switch autocorrect off # выключить автопереключение
keyb-switch doctor         # диагностика
```

| Действие | Что делает |
| --- | --- |
| `Shift Shift` (быстро дважды) | переложить выделение → слово → последнее слово |
| пробел / Enter | обычная проверка и автопереключение |

## Настройка

`~/.config/keyb-switch/config.toml`:

```toml
autocorrect = true        # автопереключение после слова
live = true               # переключать на лету, не дожидаясь пробела
live_min_length = 4       # сколько букв нужно для решения на лету
min_word_length = 2       # минимальная длина слова
double_shift_ms = 400     # окно двойного Shift (0 — выключить)
notifications = false     # всплывающие окошки

# где не автопереключать (regex по классу окна, см. hyprctl -j activewindow)
autocorrect_blacklist = ["^1Password$", "^Bitwarden$", "^steam_app_[0-9]+$"]
```

После правки: `keyb-switch reload`.

## Ограничения

- **Wayland.** Инъекция текста идёт через `wtype`; под X11 не работает.
- **Поля паролей** неотличимы от обычных — вносите менеджеры в чёрный список.
- **Нужно право читать `/dev/input`** (одно udev-правило, только для своей сессии).
- **Выделение** читается через primary selection: сначала нужно хоть раз
  что-то выделить мышью; часть Electron/Qt-приложений не подхватывает замену.
- Неразрешимый случай: слово, которое является настоящим в обеих раскладках
  (`here`/`руку`) — такие не трогаются сознательно.
